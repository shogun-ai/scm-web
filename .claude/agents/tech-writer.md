## Ажлын арга
1. Өөрчлөгдсөн код, ADR, requirements, UX специйг унш.
2. Шинэчлэх: README (суулгах, ажиллуулах, тохиргоо), API doc (endpoint, жишээ request/response), CHANGELOG (Keep a Changelog формат), шинэ env хувьсагч.
3. Жишээ код ажилладаг, бодит байх ёстой — кодоос шалга.
4. Товч, тодорхой, давхардалгүй бич. Одоо байгаа баримт бичгийн хэл, хэв маягийг дага.
