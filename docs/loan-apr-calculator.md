# Зээлийн бодит өртгийн тооцоолуур

Public `/calculator` хуудасны зээлийн нөхцөлд үйлчилгээний шимтгэлийн хоёр сонголт (анх 50,000₮, 100,000₮), даатгалын зардал (анх 0₮) байна. Үр дүн оролт өөрчлөгдөхөд шинэчлэгдэнэ.

## Тооцоолол

Хэрэглэгчийн өгсөн томьёог `shared/loanApr.js` хэрэгжүүлнэ:

1. `r = сарын хүү / 100`, `C = үйлчилгээний шимтгэл + даатгал`.
2. `A = (P + C) × r / (1 − (1 + r)^(-n))`. Тэг хүүтэй бол `A = (P + C) / n`.
3. `P = Σ A / (1 + i)^t` болох сарын `i` хүүг хоёр хуваах аргаар олно.
4. Жилийн бодит өртөг `i × 12 × 100` хувь. Жилийн нийлмэл өгөөж `(1+i)^12−1` биш.

Энэ APR нь **тэнцүү сарын төлбөрийн** суурьтай. Ердийн тооцоолуурын тэнцүү/хугацааны эцэст төлөх хуваарь үндсэн зээлийг тооцдог; зардал багтсан сарын тэнцүү төлбөр болон нийт төлбөрийг APR-ийн хэсэгт тусад нь харуулна. Одоогийн APR оролт зөвхөн үйлчилгээний шимтгэл, даатгалыг багтаана; журмын тайлбарт дурдсан бусад зардлын нэмэлт оролт энэ шаардлагад ороогүй.

0 хүү, 0 зардлыг дэмжинэ. Хугацаа 1–1200 бүтэн сар, public тохируулсан дээд хугацааны хязгаартай. Буруу оролтод хязгааргүй/NaN утга харуулахгүй.

## Админ тохиргоо

**Контент засах → Тооцоолуур → Зээлийн бодит өртгийн тохиргоо** хэсэгт дараахыг өөрчилж, доод талын Хадгалах товчоор хадгална:

- Шимтгэлийн хоёр өөр дүн, даатгалын анхны дүн.
- Талбаруудын нэр, үр дүнгийн гарчиг, тооцооллын тайлбар.
- Журмын тайлбарын эхлэл, 2.4 болон 2.5-ын гарчиг, таван заалт тус бүрийг мөрөөр.

`SiteConfig`-ийн `loan_apr_settings` түлхүүр, `rates` бүлэг ашиглана. Шинэ schema/migration шаардахгүй. Authenticated admin PUT/bulk endpoint тохиргоог бичихээс өмнө шалгана. Зардал нь 0 буюу түүнээс их бүхэл төгрөг, шимтгэлийн хоёр сонголт ялгаатай байна. Текстүүдийг HTML болгон ажиллуулахгүй.

Тохиргоо байхгүй эсвэл public fetch амжилтгүй үед анхны тохиргоогоор ажиллана. Ачаалж байгаа болон алдаа гарсан үед анхны тохиргоо ашиглаж буйг харуулж, алдаанд дахин ачаалах товч үзүүлнэ. Админд тохиргоо амжилттай ачаалагдтал засварлах/хадгалах боломж хаалттай байна. Хоосон тайлбарыг зориуд хадгалсан бол хуучин утгаар солихгүй. Тохиргоо public хуудсыг дахин нээхэд ачаална.

Журмын анхны тайлбарын эх: [Монголбанкны зээлийн бодит өртгийн тооцоолуур](https://www.mongolbank.mn/mn/loan-rate-calculator). Текст нь хэрэглэгчийн өгсөн 2.4.1–2.4.5 болон 2.5.1–2.5.5 заалтууд.
